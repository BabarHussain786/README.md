## 📈 Research Methodology

I strongly prioritize:

1. **Clear hypotheses** before experimentation  
2. **Controlled and reproducible setups**  
3. **Transparent reporting** (best, average, and variability)  
4. **Fair comparisons** with consistent settings  
5. **Interpretability of results**, not just peak values  

This methodology helps ensure that conclusions remain robust, comparable, and useful for future research.
